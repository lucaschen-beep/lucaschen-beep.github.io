隱私權政策

更新日期：2026 年 10 月 10 日

本政策適用於 AutoSEO YouTube、與其共用 Google OAuth 應用程式設定的 FB.IG Publisher，以及本說明網站。工具供獲授權的工作人員處理所管理頻道的影片作業。

一、存取與保存哪些資料

  • Google OAuth 授權憑證，用於取得與更新 API 存取權；工具不要求使用者提供 Google 帳號密碼。
  • YouTube 頻道 ID、頻道名稱、影片 ID、標題、說明、縮圖、發布狀態、可取得的排程時間，以及必要的影片資料。部分只有頻道管理者可讀取的欄位，僅在 API 權限允許時取得。
  • 使用者指定的原始影片、封面、檔案資訊、文案、排程及發布結果。
  • 執行作業所需的設定、診斷紀錄及通知內容。

二、資料用途

資料用於頻道與影片身分核對、讀取參考文案、產生使用者要求的影片文案、上傳、更新發布設定、建立素材對應、執行已確認的 Facebook／Instagram 排程、核對結果及提供通知與故障查核。Google 授權範圍以授權畫面列示的權限為準。

三、資料傳送與第三方服務

  • Google／YouTube：透過官方 API 進行授權、影片資料讀取，以及使用者要求的 YouTube 上傳或更新。
  • Gemini：AutoSEO YouTube 在使用者啟動影片分析時，將選定的本機原始影片傳送至 Gemini 進行分析。
  • OpenAI：AutoSEO YouTube 在使用者啟動文案產生時，將影片分析結果、檔名、使用者指示，以及指定 YouTube 參考影片的標題與說明傳送至 OpenAI。參考說明中包含的聯絡資訊也可能包含在請求內。這些資料用於產生本次工作所需文案。
  • Meta：FB.IG Publisher 執行已確認的發布工作時，會向 Facebook／Instagram 傳送原始影片、發布文案及適用的封面。
  • 電子郵件服務：依管理者設定傳送作業通知，內容可能包含影片名稱、連結、排程與錯誤說明。

工具不出售 Google 使用者資料，也不將其用於廣告投放或建立廣告使用者輪廓。工具的 Google 使用者資料處理須遵守 Google API Services User Data Policy，包括適用的 Limited Use 要求。第三方服務另外適用其服務條款、隱私政策及使用者所選服務方案的資料處理設定。

四、保存位置與存取

AutoSEO YouTube 的作業資料保存在管理者的 Windows 電腦，OAuth 憑證保存在 Windows 認證管理員。FB.IG Publisher 的來源資料、排程、作業紀錄及受保護的授權憑證保存在管理者控制的 NAS。系統管理者可因執行作業、維護、查核或資料處理請求而存取必要資料；備份可能保有相應副本。

作業資料可能保留至管理者清理或處理刪除請求；撤銷 Google 授權不會自動刪除既有本機、NAS 或備份資料。第三方已接收的資料依其保留政策及服務設定處理。本政策不宣稱既有版本具備固定天數的自動清除功能。

五、撤銷授權與刪除資料

使用者可前往 Google 帳戶的第三方存取權管理頁面撤銷本應用程式的 Google 授權。撤銷後，需要該授權的後續作業可能無法執行。

如需查詢或刪除工具保存的頻道資料、作業紀錄、憑證或相關備份，請聯絡 lucas.chen@wayne.com.tw，提供要處理的頻道與資料範圍，勿寄送密碼或 Token。管理者核對身分及範圍後處理，並說明仍需保留資料的原因與適用範圍。

刪除工具中的紀錄、停止使用工具或撤銷授權，不等於刪除已發布到 YouTube、Facebook 或 Instagram 的內容。平台內容的刪除需另行在對應平台處理。

六、本網站

本網站提供靜態介紹與政策說明，不設登入或資料提交表單，頁面本身未加入廣告、分析追蹤程式或第三方字型。網站託管服務仍可能因提供網站及維護安全而處理連線 IP、時間及瀏覽器等一般存取資訊。

七、聯絡與政策更新

支援與隱私聯絡：lucas.chen@wayne.com.tw。資料處理方式變更時，應同步更新本頁及更新日期。
